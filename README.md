# Miyu voice

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This repository holds Miyu's three voice packages. All three packages are optional: if you have not installed them, nothing related to voice appears in any of Miyu's interfaces.

| Package | What you can do after installing it | Command |
|---|---|---|
| `voice-input` (voice input) | Turn what you say into text on this computer, for the microphone button in the input box of the terminal UI and the web UI, and for voice messages in chats. Recognition runs on the local CPU and uses the SenseVoice model. | `miyu voice-input` |
| `say` (read aloud) | Read replies aloud with cloud speech synthesis (MiniMax, MiMo or a service with an OpenAI-compatible API). The AI can also speak on its own and send voice messages. | `miyu say` |
| `voice-assistant` (voice assistant) | Stays in the background like Siri; say the wake word and you can talk to the AI. Installing it also installs the other two packages. | `miyu listen` |

To install, you can use:

```sh
miyu pkg install voice-assistant   # install all three packages
miyu pkg install voice-input       # install voice input only
```

## Voice input

This section covers the voice input sounds and what happens when there is no sound. When you speak into the microphone in the terminal UI, a rising sound plays when listening starts and a falling sound plays when it stops. If you do not want these sounds, turn off `Voice input sounds` in the settings.

If a whole recording has no sound at all (for example, the microphone is muted or not plugged in properly, or the system's default input device has no sound), voice input reports `silent_audio` instead of saying it did not catch what you said. In that case, check the microphone, or pick another input device in the `Microphone` drop-down in the settings.

## Voice assistant

This section covers waking the voice assistant, talking to it and interrupting it. Once the voice assistant is installed and enabled, it keeps listening for the wake word as long as the core is running. The default wake word is `你好你好`. You can change it on the settings page, and the change takes effect immediately without restarting the voice assistant. To check first whether a word can be recognized, run `miyu listen wake-test <wake word>`. If you do not want the voice assistant to listen, disable it in the packages.

You can choose which persona and preset voice conversations use under `Persona` and `Preset` on the settings page; if you choose none, the default persona and preset are used. After a change, a conversation you are having with the AI is not interrupted; when it ends, the voice assistant starts a new session. The old session is kept, and you can see it in the terminal UI and the web UI.

`miyu listen` starts or ends a conversation, and you can also say which one with `miyu listen on` or `miyu listen off`:

- Starting a conversation works the same as saying the wake word: you can speak after the sound plays;
- Ending a conversation plays a different sound, and if the AI is still speaking, it stops too.

A conversation also ends on its own: if you do not start speaking within 30 seconds after waking it, or do not speak again within 30 seconds after the AI finishes, the voice assistant plays the ending sound and shows a `Conversation ended` notification. Until the conversation ends, you can simply keep talking without saying the wake word again.

During a conversation, the voice assistant shows its current state in system notifications: listening, what it recognized, thinking, how far the AI has got in speaking, did not catch that, and which step went wrong. On Linux these states are shown in one notification that keeps updating. Windows and macOS cannot replace a notification that has already been shown, so only the recognition result, the finished answer and errors are shown there.

**When the AI is speaking, it stops as soon as you start talking, even when you use loudspeakers.** This is because the voice assistant subtracts what the speakers are playing from the sound the microphone picks up (echo cancellation), so it does not take the AI's own voice for yours. However, if the speakers are much louder than your voice, the voice assistant cannot tell that you have started talking. In that case, wait for the AI to finish, or run `miyu listen off`. If you do not want to be able to interrupt, turn off `Interrupt the AI by speaking` in the settings; the assistant then starts listening to you only after the AI finishes.

How you set up a shortcut depends on the system:

- Windows and macOS: the system tray program registers the shortcut.
- Linux: Wayland does not let programs register global shortcuts themselves, so you need to add a shortcut that runs `miyu listen` in your desktop environment's shortcut settings.

## Choosing a microphone

Voice input and the voice assistant both let you choose a microphone in the `Microphone` drop-down in the settings; if you choose none, the system's default input device is used. Each system records and plays sound as follows:

- Linux: if the system has a sound server (PipeWire or PulseAudio), recording and playback both go through it (using its PulseAudio interface, so no extra library is needed). The drop-down lists the input devices from the system's sound settings, and other programs can use the same microphone at the same time. Without a sound server, the ALSA sound card is used directly.
- macOS: recording and playback go through Core Audio. The first time it records, macOS asks whether to allow microphone access, and recording works only after you allow it.
- Windows: recording and playback go through WASAPI.

## Changing the engine

If you want another speech recognition or speech synthesis engine, you do not need to replace the voice packages. After you install a package that provides an engine (for example, the DeepSeek tools bundle), the `Engine` drop-down in the voice input and read-aloud settings gets an extra entry with that package's name, listed together with the built-in engines. When you choose that engine:

- Voice input does not need to download the 163 MB local recognition model;
- Read aloud splits long text into sentences, hands them to the engine one part at a time for synthesis, and joins them into one piece of audio.

> Developers can read the core repository's `internal/designs/20-语音.md` (the voice design) and `internal/designs/67-总线.md` (how engines plug into `stt.engine` and `tts.engine`).
