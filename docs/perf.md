# 量出来的数

照核心仓库 `docs/designs/23-性能预算.md` 的量法：内存按进程分开报 RSS、PSS、私有匿名（`/proc/<pid>/smaps_rollup`），空闲一会儿再量一次；
只和这几个包自己的上一版比。量法见 `tools/e2e/measure.sh`、`run-turn.sh`（`MIYU_VOICE_MEASURE=1`）。

## 2026-11-10（施工 VO-13下，miyu-voice 7e7d1fa 加 VO-13下；核心 8f6af201e）

机器：Ryzen（主人的台式机），Arch Linux，release 版，隔离数据根，ALSA 没设备。

| 项目 | 量到的 | 预算 |
|---|---|---|
| 语音输入，空闲 | RSS 22 MB、PSS 18 MB、私有匿名 0.7 MB | 常驻几 MB（设计 20 第五节） |
| 朗读，空闲 | RSS 4 MB、PSS 1 MB、私有匿名 0.4 MB | 轻（第二节包表） |
| 助手，关着 | RSS 22 MB、PSS 18 MB、私有匿名 0.9 MB（60 秒后不变） | 装了没开不该占 |
| 识别 5.6 秒的中文，经总线来回（含 blob 上传），冷 | 1225 ms（识别子进程起来、加载模型） | |
| 同上，热 | 203～212 ms | 第五节：热的约 150 ms（旧版，不含总线来回） |
| 识别子进程 | RSS 398 MB（峰值同），闲 5 分钟退 | 重型 worker 用完就退（23 第二节） |
| 助手开着听静音（两个模型加载着） | RSS 67 MB、私有匿名 39 MB；CPU 30 秒共 10 ms（0.03%） | 待机约 80 MB、CPU 0.4%（旧版实测，第九节） |
| 一整轮里这一头：3 秒的话认字加交进会话 | 954 ms（叫醒先预热识别；不预热 2108 ms） | 说完到第一声 2 秒以内（第十二节，含模型和云端合成） |
| 交进会话、第一句凑齐到交 tts | 各 < 1 ms | |

**待补**：

- 助手开着时的 CPU 是假麦克风喂的全零量的：能量门全挡住了。真麦克风有底噪，能量门偶尔放进来，另有 cpal 回调的开销，要在真麦克风上另量（不开主人的麦，等主人在场）。
- 说完到第一声：模型的首字、云端合成的时延要真接上才量得到，这里只量了这一头的。

## 2026-11-10（施工 VO-15，句与句之间；核心 53ece42d5）

`tools/e2e/gap.sh`：一轮念两句，每句 2 秒，假的合成服务每句慢 1 秒，声音进按实时读的假音箱。

| 项目 | VO-15 前（fb07db2） | VO-15 后 |
|---|---|---|
| 两句之间 | 念完一句才合下一句，音箱每句开一次、关一次，中间静 0.70 秒（合成慢 1 秒时；真的云端合成一两秒，断得更久） | 放第一句时第二句已经在合，两句在音箱的同一次打开里连着放完，中间不静 |
| 音箱开着多久 | 放完就关 | 放完再开 1.5 秒（`speaker::LINGER`），这之内来的接着放 |

## 2026-11-11（施工 VO-20，回声消除；核心 30b83a93b）

她的声音改由助手自己的音箱放，麦克风收到的先过回声消除（`sonora` 0.3.0，WebRTC AEC3 的纯 Rust 移植）。都是模拟量的：两段 16 kHz
的录音，一段当她（经音箱漏回麦克风：晚 90 毫秒起四条回声），一段当你，没有碰真麦克风、真音箱。

| 项目 | 量到的 |
|---|---|
| 只有她的声音漏回来（漏回来的比你平时说话响 5 分贝） | 麦克风里 −17 分贝，消掉以后 −47～−66 分贝；人声检测一次没报「有人开口」 |
| 同上，她一开口就量（还没学过这间屋子） | 头半秒 −59 分贝以下，0.5～2 秒 −35～−39 分贝，没报开口 |
| 同上，音箱再响一倍（比你响 11 分贝） | 0.5～2 秒剩 −31 分贝，人声检测报了一次开口；这时消掉前后差 20 分贝，照「主要是她自己」不算打断 |
| 你和她一起说（她比你响 5 分贝以内） | 报开口、她停；重叠那一段你的话轻了约 5 分贝，认出来的字缺头 |
| 你和她一起说（她比你响 11 分贝） | 没报开口，打断不了 |
| 处理 7.2 秒的声音 | 22 毫秒（一个核的 0.3%）；只在音箱出声和之后 1 秒里过 |
| 假音箱上句与句之间（`gap.sh`） | 同 VO-15：两句在音箱的同一次打开里连着放完 |

**待补**：真音箱、真麦克风上外放时会不会自己打断自己、你开口她停不停，等主人在场量；`echo::MOSTLY_ECHO_DB`（15 分贝）到时照实际的调。
